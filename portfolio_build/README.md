# SAI AKSHHAYAA M P — Data Analyst Portfolio

A responsive static portfolio website built around the supplied portfolio requirements and real project screenshots.

## Run locally

No build tools are required.

1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

3. Visit `http://localhost:8000`.

## Structure

- `index.html` — homepage
- `styles.css` — responsive styling
- `script.js` — mobile navigation
- `projects/` — six recruiter-focused case studies
- `assets/` — project screenshots and supporting assets

The site uses only local HTML/CSS/JS and the supplied image assets, so it can be deployed to static hosting.
